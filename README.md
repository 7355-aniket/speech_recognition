# 🎙️ Speech Recognition System

A Python-based **Speech Recognition System** that converts human speech into text using speech processing and machine learning techniques. The project captures audio through a microphone, processes the input, and generates the corresponding text output.

## 🚀 Features

* 🎤 Real-time speech input using a microphone
* 📝 Converts speech into text
* 🔊 Supports natural human voice commands
* ⚡ Fast speech-to-text processing
* ❌ Handles unclear or unrecognized speech
* 💻 Simple and beginner-friendly implementation

## 🛠️ Technologies Used

* **Python**
* **SpeechRecognition**
* **PyAudio**
* **Google Speech Recognition API**
* **NumPy**
* **Audio Processing**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Speech-Recognition.git
cd Speech-Recognition
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install required libraries

```bash
pip install -r requirements.txt
```

If you don't have a `requirements.txt` file:

```bash
pip install SpeechRecognition PyAudio
```

## ▶️ How to Run

Run the Python program:

```bash
python speech_recognition.py
```

Speak into your microphone when prompted.

### Example

```text
Listening...

You said: Hello, how are you?

Recognized Text:
Hello, how are you?
```
